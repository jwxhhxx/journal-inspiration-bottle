# 🫙 手账灵感瓶 Journal Inspiration Bottle

一个给手账设计师 / 画师用的灵感生成器。摇一摇瓶子，随机吐出一张「风格 + 元素」的灵感小纸条，塞进瓶子里，点击瓶子就能翻看历史灵感。

纯静态单文件页面，零依赖，双击 `index.html` 即可离线使用。

**在线体验：** https://jwxhhxx.github.io/journal-inspiration-bottle/

## 功能

- **摇一摇生成灵感** — 随机组合风格与元素，只给「一点提示」，不把画面描述死，留给画师自由发挥
- **30 种风格** — 极简、盐系、甜系、森系、韩系、蒸汽波、莫兰迪、多巴胺、像素风、剪纸风……
- **800+ 元素，8 个分类** — 食物 / 水果 / 植物 / 动物 / 盐系小元素 / 日常用品 / 天空与天气 / 节日限定
- **自定义元素** — 「查看所有元素」弹窗里可以按分类添加自己的元素词，摇一摇时与内置元素池一起抽取（✦ 标记）
- **可选生成数量** — 每次想要 1~8 个元素都能设定
- **形容词修饰** — 按元素分类自动搭配贴切的形容词，约 30% 保持朴素，避免画面过满
- **40 条手账小提示** — 覆盖组合思路、构图排版、上色技法、拼贴装饰、细节加料
- **纸条管理** — 历史最多 100 张，支持标记「已完成」（划线置灰）、「粉碎纸条」、一键清空、复制
- **瓶中纸条** — 纸条随机堆在瓶子左右两侧的空白区，随数量自动增高、自动重排

## 使用

直接用浏览器打开 `index.html`。

所有数据（历史灵感、自定义元素、分类与数量偏好）都保存在浏览器 `localStorage` 里，不会上传到任何服务器。

## 本地预览（可选）

```bash
python -m http.server 8080
```

然后访问 http://localhost:8080

## 部署

推送到 `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages（见 `.github/workflows/deploy.yml`）。

## 技术

单文件 HTML + CSS + 原生 JavaScript，无框架、无构建步骤。
